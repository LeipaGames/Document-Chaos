# Document Chaos
## Popis hry
Hra Document Chaos je hra typu Tycoon, odehrávající se v rušném úřadu. Do úřadu přicházejí návštěvníci, kteří potřebují vyřídit záležitosti v několika různých patrech. Vaším úkolem je z vydělaných peněz rozšiřovat kapacitu kanceláře a přidávat nová patra

## Ovládání
* **Levé tlačítko myši (LMB)** - Nákup kanceláři, nebo pater
* **ESC** - Ukončení hry

## Postup spuštění (Windows)
1. Stáhněte ze sekce Releases `Document.Chaos.zip`.
2. Rozbalte stažený `.zip` soubor.
3. Spusťte soubor `Document Chaos.exe`

## Použité technologie
* **Herní engine:** Unity
* **Vývoj a verzování:** VS Code a Github
* **Grafika:** Piskelapp.com
* **AI nástroje:** Github Copilot, Claude, Gemini
